# 🧠 CSET419 -- Introduction to Generative AI

## 📌 Lab 10: Sequential Data Generation using RNN, LSTM, and Transformer

------------------------------------------------------------------------

## 🎯 Objective

The objective of this lab is to implement generative models capable of
learning patterns from sequential data and generating new sequences
using RNN, LSTM, and Transformer models.

------------------------------------------------------------------------

## 📚 Learning Outcomes

-   Understand sequential data generation\
-   Preprocess sequence datasets\
-   Implement generative models\
-   Train neural networks\
-   Evaluate generated outputs

------------------------------------------------------------------------

## 🔍 Sequential Data Generation

Sequential data generation involves predicting the next element in a
sequence based on previous elements.

Examples: - Text\
- Speech\
- Time-series\
- Music\
- DNA

------------------------------------------------------------------------

## ⚙️ Approaches

-   Markov Models\
-   N-grams\
-   RNN\
-   LSTM / GRU\
-   Transformer

------------------------------------------------------------------------

# 🧪 Component I: LSTM Model

## Steps

1.  Load dataset\
2.  Tokenize text\

4.  Apply padding\
5.  Build LSTM model\
6.  Train model\
7.  Generate text

## Dataset

artificial intelligence systems learn patterns from data.\
